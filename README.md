# 🎮 Gaming Blog Website

A multi-page gaming and esports news website built to practice professional frontend development concepts using HTML, CSS, and JavaScript.

This project focuses on semantic HTML structure, responsive layouts, accessibility, SEO basics, GitHub workflow, and interactive JavaScript features.

---

# 🚀 Features

* Multi-page website structure
* Semantic HTML5 layout
* Responsive design
* Gaming news articles
* Tournament section
* Contact page
* FAQ section
* Embedded media support
* Navigation system
* Accessibility improvements
* SEO-ready structure
